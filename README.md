# Olá! Eu sou o Felipe ✌️

Desenvolvedor Full Stack apaixonado por tecnologia e inovação, com experiência no desenvolvimento de aplicações web modernas utilizando React.js, Next.js, Node.js, TypeScript, Prisma e MongoDB. Também possuo vivência com Laravel, Tailwind CSS e integrações em plataformas como VTEX IO, Shopify e Tray.
 
Atuo tanto no Front-End quanto no Back-End, criando soluções completas, desde a construção de interfaces intuitivas e responsivas até o desenvolvimento de APIs robustas e escaláveis. Tenho foco em performance, organização de código e boas práticas de desenvolvimento.
 
Minha missão é transformar ideias em experiências digitais eficientes e bem estruturadas, sempre buscando evolução contínua e adoção de novas tecnologias.
 
Estou sempre aberto a novos desafios e oportunidades para crescer como profissional!
